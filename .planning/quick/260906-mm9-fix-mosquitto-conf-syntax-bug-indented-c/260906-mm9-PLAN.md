<objective>
Fix a fatal syntax error in `deploy/mosquitto.conf` that crash-loops the broker, and audit the rest of the file for the same class of defect.

Purpose: mosquitto 2.1.2 terminates with exit code 3 on startup — `Error found at /mosquitto/config/mosquitto.conf:20.` / `Error: Unknown configuration variable '#'.` Nothing listens on 1883 or 9001, so every check in `scripts/smoke_test_broker.py` fails with "Connection refused". This is the single blocker making the broker unreachable.

Root cause: mosquitto's config parser does not support trailing inline comments after a directive, and requires a comment's `#` to sit at column 0. Line 19 puts an inline comment after `autosave_interval 60`; line 20 is an indented continuation of that comment. The indented line is tokenized as a directive whose name is literally `#`, producing the live error.

Output: a `deploy/mosquitto.conf` that parses cleanly, with the `autosave_interval` rationale preserved as a column-0 comment block above the directive — matching the convention already used by the "global settings" block at the top of this same file.
</objective>
