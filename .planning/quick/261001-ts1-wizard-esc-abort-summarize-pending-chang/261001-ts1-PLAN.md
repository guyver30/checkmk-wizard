<objective>
Let the operator leave checkmk-wizard at any prompt in Phases 1-4 with Esc (Ctrl+C behaves the same). On abort the wizard
lists the site's pending (not yet activated) changes and asks whether to Apply (activate), Revert (discard ALL pending
changes via Checkmk's GUI "Revert changes" action), or Leave them pending, then exits. Esc is disabled from Phase 5
onward because Phase 5 changes remote machines over SSH, which no Checkmk revert can undo.

Purpose: no more half-finished runs that leave pending changes for the next run to force-activate silently.
Output: api.revert_pending_changes(), the abort mechanism and handler in wizard.py, tests, docs.
</objective>
