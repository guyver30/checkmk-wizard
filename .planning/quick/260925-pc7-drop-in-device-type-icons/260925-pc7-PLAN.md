# Drop-in device-type icons
Files under `dashboard-react/src/assets/icons/device-types/` named `<device_type>.svg` are loaded via `import.meta.glob` in `src/lib/mapIcons.ts`; the sidebar tree (`TreeNode.tsx`) consumes the same SVGs via CSS mask, replacing `display.ts`'s `deviceTypeIcon()` class table. Existing icons renamed to device-type names. Tests + README §5b updated.
