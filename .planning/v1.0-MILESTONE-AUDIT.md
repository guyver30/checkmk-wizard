### Functional gaps worth fixing

1. **DASH-04/DASH-05, poller-liveness signal missing.** The retained `lan/poller/status` is stored
   but no component shows "poller offline since HH:MM"; the vanilla dashboard's banner did not
   survive the 11.1 rewrite. A dead poller still greys hosts out via per-device STALE, but with no
   explicit signal.
2. **Wizard re-promotion can wipe dashboard metadata.** `_create_or_update_host` falls back to a
   REPLACE PUT (`update_host_attributes`) carrying only wizard-owned attributes; parents,
   `map_position`, `criticality` and `depends_on` set in the dashboard on a still-IP-named host are
   dropped when the host is promoted. The other wizard update path read-merges correctly.
