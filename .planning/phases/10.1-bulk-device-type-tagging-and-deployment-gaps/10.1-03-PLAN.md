**3. `async def _retag_existing_hosts(client, connection, *, exclude_names: set[str]) -> None`** — the flow itself:

b. Build candidates via `_untagged_host_candidates(hosts, exclude_names)`. If empty, print one dim line saying nothing needs retagging and return **without prompting** — a run with nothing to fix must not grow a prompt.

e. Folder loop. Compute the distinct folders present among the remaining candidates and `questionary.select` one, with each choice labelled with the folder and its candidate count. The prompt message must state in plain words that only hosts in exactly that folder are touched and that sub-folders are not (D-03).
