### REPLACE-Safe Write Shape (independently re-checked)

`_write_host_attributes` (`wizard.py:1053-1098`) is the single write path used by both the device-type write and the opt-in alias write (`_prompt_optional_aliases` calls it too). It: (1) GETs the host, (2) reads the ETag from that same response's headers, (3) takes `resp.json()["extensions"]["attributes"]` as the base dict, (4) pops `meta_data`, (5) applies `overrides`, (6) PUTs the whole dict with the ETag from step 2. This is fetched fresh per host, per call — never batched — matching plan 10.1-01's live REPLACE verdict and the phase's non-negotiable "REPLACE-safe write shape" requirement.
