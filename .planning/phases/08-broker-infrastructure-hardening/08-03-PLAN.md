Add an inline comment stating this so a future reader does not "simplify" the check back into a false positive.

Cleanup: after the checks, connect as the poller user and publish a zero-length payload with `retain=True` to both `lan/smoketest/seed` and `lan/smoketest/deny-check`, clearing the retained values so the test leaves no ghost entries in the `lan/` namespace that Phase 11's dashboard would later render. Guard the entry point with `if __name__ == "__main__":` so `--help` and imports work with no network access.
