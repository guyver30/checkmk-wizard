  <action>
Write `deploy/gen-mosquitto-passwd.sh`, a bash script that regenerates `deploy/mosquitto.passwd` from scratch. Password hashing MUST come from the real `mosquitto_passwd` binary (argon2id by default) — do not hand-roll any hash.

Runtime selection, in this priority order: (1) `podman` if on PATH, (2) `docker` if on PATH, (3) a host-installed `mosquitto_passwd` if on PATH. If none are available, print a clear message naming all three options and exit 1.

Container invocation details that matter:
- Image: `eclipse-mosquitto:2`.
- Bind-mount the script's own directory — resolve it from `$0`, not `$(pwd)`, so the script works from any cwd — to `/passwd` with the `:z` SELinux relabel suffix, and target `/passwd/mosquitto.passwd`.
- For `podman`, pass `--user 0:0`. Under rootless Podman, container UID 0 maps to the invoking host user, so the generated file lands owned by that user; without this flag the file is created as a subuid and the host user cannot chmod, edit, or commit it. For `docker`, pass `--user "$(id -u):$(id -g)"` instead, since Docker's UID 0 is real host root.
- Use `--rm` for both.

Generation sequence: first `mosquitto_passwd -b -c <file> wsreader wsreader`, then `mosquitto_passwd -b <file> poller poller`. The `-c` flag creates/overwrites and MUST appear only on the first invocation — including it on the second wipes the first user. Read the usernames and default passwords from shell variables declared at the top of the script (`WS_USER`, `WS_PASSWORD`, `POLLER_USER`, `POLLER_PASSWORD`) that can be overridden from the environment, so an operator rotating credentials edits nothing.

After generation: `chmod 644` the resulting file (RESEARCH Pitfall 4 — the broker runs as non-root UID 1883 and must read the bind-mounted file), then verify the file has exactly two lines, one starting `wsreader:$` and one starting `poller:$`, and exit non-zero with a diagnostic if not.

Header comment must state: these are disposable dev/local defaults matching this project's existing `cmkadmin`/`cmkadmin` and `minioadmin`/`minioadmin` convention (D-09), rotate before exposing beyond a trusted LAN, and re-running this script is the supported rotation path. Make the file executable (`chmod +x`).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN client → Mosquitto listener (1883 / WS 9001) | Untrusted network clients cross here on CONNECT; this plan's config is the only enforcement point |
| Repo / VCS → operator eyes | The credential file is deliberately checked in and therefore readable by anyone with repo access |
| Host filesystem → container process (UID/GID 1883) | Bind-mounted config/credential files must be readable by a non-root in-container user |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Spoofing | Both listeners (CONNECT path) | mitigate | `allow_anonymous false` + `password_file /mosquitto/config/mosquitto.passwd` in `deploy/mosquitto.conf`, replacing the baseline `allow_anonymous true` |
| T-08-02 | Tampering | WebSockets listener (PUBLISH path) | mitigate | `user wsreader` / `topic read lan/#` in `deploy/mosquitto.acl` — no write grant, so browser clients cannot forge or clear retained device state |
| T-08-03 | Elevation of Privilege | ACL default-deny path | mitigate | No bare `topic` lines outside a `user` block (those apply only to anonymous clients); any authenticated user without a `user` block gets zero access |
| T-08-04 | Information Disclosure | `deploy/mosquitto.passwd` in VCS | accept | Documented disposable dev/local defaults per D-09, same precedent as `cmkadmin`/`minioadmin`; hashes are argon2id and `deploy/gen-mosquitto-passwd.sh` supports env-var overrides for rotation before wider exposure |
| T-08-05 | Denial of Service | Broker startup vs. bind-mount permissions | mitigate | `chmod 644` on `mosquitto.conf`/`mosquitto.acl`/`mosquitto.passwd`; the in-container broker runs as non-root UID/GID 1883 and fails to start on unreadable auth files (RESEARCH Pitfall 4) |
| T-08-06 | Information Disclosure | Browser clients reading `$SYS/#` broker internals | mitigate | `wsreader` scoped to `lan/#` rather than `#` |
