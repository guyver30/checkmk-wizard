<objective>
Extend the Phase 9 poller contract with the two additive fields D-17 locks: Checkmk's own
`staleness` value, and the real host state so DOWN and UNREACHABLE can be told apart.

Purpose: DASH-04 needs an authoritative staleness signal (with a timestamp-age fallback), and
D-11/Pitfall 6 need UNREACH to be separately renderable. `compute_overall_state()` today
collapses raw host states 1 and 2 into the single string `"DOWN"`, so the distinction is not
recoverable from the existing payload.

Output: two new payload keys on `lan/devices/{id}/status`, tests covering their defaults, the
topic-contract doc updated, and a dated live-probe result recorded for the `staleness` column.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Livestatus TCP → poller | Checkmk-sourced row values (including the new `staleness` cell) cross into the poller |
| poller → MQTT broker | New payload keys become readable by every `lan/#` subscriber, including browsers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Denial of Service | `query_devices()` staleness extraction | mitigate | Per-row `except (IndexError, TypeError, ValueError)` with a `None` default — a malformed cell can never abort the poll cycle, matching the existing `alias` guard |
| T-11-02 | Information Disclosure | new payload keys on `lan/devices/{id}/status` | accept | `staleness` (a float) and `host_state_raw` (an enum of three constants) carry no credentials or PII; the topic is already readable by `wsreader` by design (Phase 8 D-03) |
| T-11-03 | Tampering | `OPTIONAL_HOST_COLUMNS` growth | mitigate | `staleness` is optional, so an absent/renamed column degrades to `None` rather than raising `LivestatusError` and halting the poller |
| T-11-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan — `uv add` is explicitly forbidden by Task 1's acceptance criteria; nothing to audit |
</threat_model>
