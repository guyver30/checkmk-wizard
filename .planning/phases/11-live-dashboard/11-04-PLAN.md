`dashboard/js/staleness.js`:
- `isDeviceStale(devicePayload, nowMs = Date.now())` — when `devicePayload.staleness` is neither
  null nor undefined, compare it directly against `STALENESS_FACTOR` (Checkmk expresses
  staleness in check-interval multiples already, the same shape as its own UI setting, per
  D-12's rationale). Otherwise fall back to timestamp age: `(nowMs - Date.parse(timestamp))/1000
  >= STALENESS_FACTOR * POLL_INTERVAL_SECONDS`. A missing or unparseable `timestamp` must
  return `true` (unknown age is not fresh) rather than throw.
- `isPollerStale(pollerStatusPayload, nowMs = Date.now())` — `true` when the payload is absent
  or its `status` is `"offline"` (the LWT fired), `false` when `last_poll` is null (a birth
  message that has not yet had a cycle), otherwise the same factor applied to `last_poll` age.
- `pollerOfflineSince(pollerStatusPayload)` — returns the Date to render in D-14's locked banner
  string, derived from `last_poll` when present and `since` otherwise, or null.
- Header comment must cite D-12's reasoning for the 3x factor (Checkmk's own default is 1.5x but
  its checks are scheduled locally, whereas this chain adds a Livestatus query, an MQTT publish,
  a broker hop and a browser — 3x absorbs exactly one fully missed cycle) and D-17's
  prefer-Checkmk's-value rule, in this repo's cite-why comment style.

`dashboard/js/display.js`:
- `displayName(devicePayload)` — D-18: the `alias` when it is a non-empty string after trimming,
  otherwise `id`.
- `effectiveState(devicePayload)` — returns `"UNREACH"` when `host_state_raw === "UNREACH"`,
  otherwise the payload's `state`. Its comment must record RESEARCH.md Pitfall 6 explicitly:
  `state` structurally cannot contain `"UNREACH"` because `compute_overall_state()` collapses
  raw host states 1 and 2, so reading `state` alone would leave the UNREACH branch permanently
  dead.
- `stateClass(state)` — maps a state string to its CSS class (`state-ok`, `state-warn`,
  `state-crit`, `state-down`, `state-unknown`, `state-unreach`, `state-pend`), lowercasing and
  defaulting unknown inputs to `state-unknown`.
- `stateIcon(state)` and `deviceTypeIcon(deviceType)` — return the locked icon CLASS NAME strings
  from this plan's interfaces block (e.g. `"icon-close-circle-filled"`). They must never return
  an emoji character; the pre-KONE `⛔` glyph is superseded by UI-SPEC. `deviceTypeIcon` defaults
  to `icon-circle` for an unrecognised type and returns `icon-question-circle` (the outline
  variant, distinct from the filled one used for the UNKNOWN host state) for `"unknown"`.
- `isTagGroupMissing(devicePayload)` — true when `device_type === "unknown"`, the D-16 trigger.
- `formatRelativeTime(isoString, nowMs = Date.now())` — a compact relative string for the
  Last Update column and the stale tooltip (e.g. `"12s ago"`, `"4m ago"`, `"2h ago"`); returns a
  neutral placeholder rather than `NaN` for an unparseable input.
- `formatClock(isoString)` — `HH:MM` for D-14's locked banner string.

Every function must tolerate a payload that predates plan 11-01 (no `staleness`, no
`host_state_raw` key) and a malformed payload, returning a safe default instead of throwing —
the same defensive-parse posture `query_devices()` applies per-column in the poller.
