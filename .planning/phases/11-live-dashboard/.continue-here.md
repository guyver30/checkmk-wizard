## Critical Anti-Patterns (do NOT repeat these)
- [SCOPE CREEP BACK]: the vis-network topology map, agent CPU/RAM/disk gauges, and per-service status were deliberately moved to Phases 13 and 12 → plans 11-09 and 11-10 carry acceptance criteria that assert their **absence**; if a task starts reaching for the `services` Livestatus table or a graph library, stop.
- [TREATING BACKOFF AS A CONFIG FLAG]: mqtt.js's `reconnectPeriod` is a **fixed** interval, not exponential and not jittered → 11-05 mandates `reconnectPeriod: 0` plus a hand-rolled wrapper driven off `close`/`offline`/`connect`, asserted by `grep -Ec 'reconnectPeriod: *[1-9]'` returning 0.
- [APPENDING TO MQTT PAYLOADS]: every topic ships a complete bounded snapshot, never a delta → all client-side merge logic must be wholesale-replace-per-topic. Appending silently duplicates state.
- [`innerHTML` WITH HOST-SUPPLIED STRINGS]: hostnames and aliases come from the broker → `textContent` only, enforced by `grep -Ec 'innerHTML|outerHTML|insertAdjacentHTML'` returning 0 on all four DOM-writing modules, plus `CSS.escape` on externally-sourced selector values and `encodeURIComponent` on the query-string id.
- [REMOVING OR REPURPOSING POLLER PAYLOAD FIELDS]: D-17 permits an **additive** extension only → copy the existing `alias` field's shape through `DeviceSnapshot` → `select_host_columns()` → `query_devices()` → `publish_device_status()`, and extend `tests/test_mqtt_poller.py` alongside.
