## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | topic construction against real host names | mitigate | Step 5's `mosquitto_sub -t 'lan/#' -v` is the live check for unexpected nested topic branches under `lan/devices/` (RESEARCH.md Pitfall B's stated warning sign); any such branch is a failed verification, not a cosmetic issue |
| T-09-02 | Information Disclosure | `podman compose logs poller` output | mitigate | Step 2 explicitly instructs checking that no log line contains the MQTT password, verifying `PollerConfig.__repr__`'s masking under real conditions |
| T-09-10 | Tampering | `check_ghost_tombstone` on a production-ish stack | mitigate | The ghost node id `smoketest-ghost` cannot collide with a real Checkmk host name, and the poller republishes correct topology on its next cycle; the check writes to no real device topic |
| T-09-11 | Denial of Service | `--kill-cmd` during `check_lwt_offline` | accept | The check kills and restarts only the `poller` container; monitoring itself (Checkmk) and the broker's retained state are untouched, and `restart: unless-stopped` plus `--start-cmd` bring it back within one cycle |
