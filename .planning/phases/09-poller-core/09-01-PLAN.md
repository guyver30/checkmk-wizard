<objective>
Build the non-networked half of the standalone MQTT poller: environment-driven configuration, the pure state/topology/bounded-log helpers, and the Livestatus query layer that turns one `GET hosts` round trip into typed `DeviceSnapshot` records.

Output: `scripts/mqtt_poller.py` (config + pure helpers + Livestatus layer, no MQTT yet) and `tests/test_mqtt_poller.py`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Checkmk site -> poller (Livestatus TCP, `checkmk:6557`) | Livestatus has no authentication of its own and returns every host known to Checkmk, including hosts created outside this project's wizard. Host names and response bytes are untrusted input crossing into the poller. |
| Container environment -> poller process | MQTT and Livestatus connection settings, including `MQTT_PASSWORD`, arrive as environment variables set by `deploy/compose.yaml`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | `query_devices` / `device_status_topic` in `scripts/mqtt_poller.py` | mitigate | `is_publishable_device_id` rejects any host name that is empty, whitespace-only, contains `+`, `#`, `/`, or ASCII control characters; `query_devices` skips and logs those rows so no untrusted name is ever interpolated into an MQTT topic string (RESEARCH.md Pitfall B) |
| T-09-02 | Information Disclosure | `PollerConfig` in `scripts/mqtt_poller.py` | mitigate | `PollerConfig.__repr__` masks `mqtt_password` as `***`; no code path logs the raw config object or an environment dump |
| T-09-03 | Denial of Service | `_livestatus_request` / `query_devices` | mitigate | Narrow `except (TimeoutError, OSError)` and `except (json.JSONDecodeError, ValueError)` normalize every failure into `LivestatusError` so Plan 09-02's poll loop can skip one cycle instead of the daemon dying; no bare `except Exception` anywhere in the module |
| T-09-04 | Spoofing | Livestatus TCP channel | accept | Livestatus is unauthenticated by design and is reachable only on the internal `cmk_net` bridge (never published to the LAN — see the Podman setup doc §5). Accepted network-isolation tradeoff already locked before this phase; not reopened here |
| T-09-SC | Tampering | Package installs | mitigate | This plan installs nothing. `paho-mqtt` 2.1.0 is already a vetted `pyproject.toml` dependency (RESEARCH.md Package Legitimacy Audit: Approved, no `[ASSUMED]`/`[SUS]`/`[SLOP]` entries); no `uv add`/`pip install` runs in this plan |
