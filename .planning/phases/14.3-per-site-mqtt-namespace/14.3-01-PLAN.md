| poller -> broker | every publish lands in a namespace other sites may share |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14.3-01 | Tampering | set_site_id / CMK_SITE_ID | mitigate | `_SITE_ID_RE.fullmatch` rejects `/ + #`, whitespace, newline; main() exits 2 before any client exists |
| T-14.3-02 | Information disclosure | unprefixed publish if prefix unset | mitigate | site_topic() raises RuntimeError when set_site_id was not called, so no code path can publish to the bare `lan/` namespace |
| T-14.3-03 | Spoofing | two unconfigured sites both default to dmc | mitigate | WARNING logged when CMK_SITE_ID unset; compose always sets it (default A2) |
| T-14.3-04 | Tampering | admin/cmd from another site | mitigate | poller subscribes and matches only site_topic(TOPIC_ADMIN_CMD); existing retained-delivery ignore at ~1658 unchanged |
</threat_model>
