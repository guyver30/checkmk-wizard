<objective>
Scope the broker ACL to the deployment's site subtree (locked "ACLs" decision, default A5): render `deploy/mosquitto.acl.template` at mosquitto container start with `CMK_SITE_ID`, keep temporary legacy poller grants for the cutover sweep, and update the live broker smoke test to the new topics.

Decision justification (CONTEXT asked the planner to choose template vs `sites/+/...` wildcard): Mosquitto ACL files have no env expansion and `pattern` only substitutes `%u`/`%c` (mosquitto-conf(5)), and usernames are not site ids. A `sites/+/lan/#` wildcard would let any dashboard login read every site on a shared broker, which defeats the namespace. Rendering at container start matches the existing pattern (the entrypoint already generates `mosquitto.passwd`), grants exactly the locked text, and is the same mechanism later per-site users can reuse.

Output: template + render script + compose wiring + unit test + updated smoke test + config comments.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (wsreader/wsadmin credentials served openly) -> broker | untrusted clients; the ACL is the only control |
| deploy/.env CMK_SITE_ID -> render script -> ACL file | operator input becomes broker security config |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14.3-05 | Information disclosure | wsreader/wsadmin cross-site read on a shared broker | mitigate | exact `sites/<id>/...` grants rendered per deployment, no `sites/+/` wildcard; exact-grant unit test in tests/test_mosquitto_acl.py |
| T-14.3-06 | Information disclosure | legacy `lan/#` retained data readable by dashboards | mitigate | wsreader/wsadmin lose `lan/#`; live check_wsreader_cannot_read_legacy; Plan 04 sweep clears the data |
| T-14.3-07 | Tampering | sed/ACL injection via CMK_SITE_ID | mitigate | charset `case` guard + shape grep before sed in render-mosquitto-acl.sh; container start aborts under `set -eu` |
| T-14.3-08 | Elevation of privilege | wsadmin writing outside its admin/cmd | mitigate | single write grant `sites/<id>/admin/cmd`; check_wsadmin_publish_lan_denied |
| T-14.3-09 | Denial of service | poller legacy tombstones silently dropped | mitigate | temporary `readwrite lan/#`, `admin/#` poller grants with removal TODO; check_poller_legacy_write |
| T-14.3-10 | Elevation of privilege | temporary poller legacy grants wider than needed | accept | poller is the trusted internal publisher on the private compose network; removal tracked by the TODO in the template |
</threat_model>
