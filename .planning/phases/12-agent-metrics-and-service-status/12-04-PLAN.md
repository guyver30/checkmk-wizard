## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Store payloads → rendered DOM | `plugin_output`, service descriptions and device aliases originate from Checkmk check plugins and are untrusted text |
| URL query string → route | `?id=` is attacker-controllable in a shared/bookmarked link |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-11 | Tampering (stored XSS) | service table Output cell, history strip | mitigate | Render every untrusted string as plain JSX text content; `dangerouslySetInnerHTML` is forbidden and asserted absent by a grep criterion |
| T-12-12 | Information Disclosure | "Device not found" copy | accept | It echoes the caller's own `?id=` value back as text only; no store contents are disclosed for an unknown id, and React escapes the echo |
| T-12-13 | Denial of Service | route render with a large service list | accept | The poller bounds what it publishes per device (~20 services), and the table renders a plain list with no per-row effect or subscription |
| T-12-SC | Tampering | package installs | accept | No `npm install` this phase; every component comes from the already-vendored `kone-design-system` tarball |
</threat_model>
