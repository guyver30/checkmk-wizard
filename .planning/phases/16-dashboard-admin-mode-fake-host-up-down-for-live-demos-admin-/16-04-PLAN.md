<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| nginx -> browser (`/admin-config.json`) | Write-capable login, fetched only with `?admin=1` |
| broker -> browser (`admin/ack`, `admin/faked`) | JSON parsed in the browser |
| browser -> broker (`admin/cmd`) | Browser publishes commands; poller re-validates everything |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-16 | Information disclosure | `loadAdminConfig` | mitigate | Fetched only when `?admin=1` is present at load; normal pages never request it; `cache: "no-store"` |
| T-16-17 | Tampering | `parseAdminAck`, `parseAdminFaked` | mitigate | Defensive parsing, unknown states dropped, handler never throws (keeps last-known-good) |
| T-16-18 | Tampering | `publishAdminCommand` | mitigate | `retain: false`, QoS 1, id correlation; poller is authoritative and re-validates (Plans 01/02) |
| T-16-19 | Spoofing | browser-side admin flag | accept | `?admin=1` is UI only; the authorization boundary is the broker ACL (Plan 03); without the wsadmin login a publish is dropped by the broker |
</threat_model>
