<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| broker -> poller (`admin/cmd`) | Untrusted command payloads; only wsadmin can write there (Plan 03 ACL) |
| poller -> Livestatus | Write-capable text protocol |
| poller -> broker (`admin/ack`, `admin/faked`) | Admin-only topics outside `lan/` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-05 | Tampering | `AdminCommandWorker.submit` | mitigate | Drop `msg.retain` deliveries; dedupe the last 64 ids so a QoS 1 redelivery never runs twice |
| T-16-06 | Denial of service | worker queue | mitigate | Bounded queue (8) with immediate "poller busy" ack; cap of 200 hosts per command from Plan 01; work runs off the poll loop so status publishing is never delayed |
| T-16-07 | Tampering | `process_one` | mitigate | Hosts resolved against the latest Livestatus snapshot; only snapshot ids and addresses reach `build_admin_commands` |
| T-16-08 | Information disclosure | `admin/faked`, `admin/ack` | mitigate | Topics outside `lan/` (D-09) so wsreader's `read lan/#` never matches; ack detail truncated to 200 chars |
| T-16-09 | Repudiation | admin commands | mitigate | One INFO log line per command with id, action and counts |
</threat_model>
