| LAN client -> nginx `/admin-config.json` | Open endpoint handing out a write-capable broker login (D-07) |
| browser -> Mosquitto (WebSockets) | ACL decides who may write admin/cmd |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-10 | Elevation of privilege | `/admin-config.json` | accept | User decision D-07 for a closed demo network; documented in the nginx comment, .env.example and docs (Plan 07); `ADMIN_ALLOW_CIDR` deferred |
| T-16-11 | Elevation of privilege | mosquitto ACL | mitigate | wsadmin's only write is `admin/cmd`; default-deny ACL; live-checked by `check_wsadmin_publish_lan_denied` |
| T-16-12 | Information disclosure | admin topics | mitigate | Admin topics outside `lan/`; `check_wsreader_cannot_read_admin` proves wsreader cannot read them |
| T-16-13 | Information disclosure | `/config.json` | mitigate | Admin credential only on the separate exact-match location; `/config.json` unchanged (acceptance criterion) |
| T-16-14 | Tampering | nginx string literal | mitigate | Generated URL-safe password (no quotes, `$`, braces, `;`, whitespace), same rule as WS_PASSWORD |
| T-16-15 | Spoofing | weak/default credential | mitigate | `${ADMIN_WS_PASSWORD:?}` in compose: no default password, stack refuses to start without a generated one |
