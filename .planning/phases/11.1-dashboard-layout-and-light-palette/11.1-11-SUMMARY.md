## Accomplishments

- Built `src/hooks/useNowTick.ts`: the app's single periodic clock. `CLOCK_TICK_MS = 12000` is
  inherited verbatim from `dashboard/js/render-shell.js` line 53; the hook clears its interval
  on unmount (no timer leak — T-11.1-18). A code comment explicitly records that the value was
  **not** re-tuned for D-34's "revisit once panes are resizable" concern: in the vanilla
  implementation a tick drove three full `replaceChildren` rebuilds (cost scaling with tree
  size), but here a tick only advances a `nowMs` value that flows into derived props, which
  React's reconciler patches in place regardless of tree size.
- Wired `useNowTick()` into `IndexRoute.tsx` as the sole `nowMs` source, threaded into
  `buildTree` and the stats-strip selector; confirmed exactly one `useNowTick()` call and zero
  `setInterval` calls in the route file.
- Built `src/components/StaleStability.test.tsx`: seeds two devices in two different tree
  groups (one ages out via the timestamp fallback, one is pinned fresh via an explicit
  Checkmk-authoritative `staleness: 0` field as a true control), expands both groups, focuses a
  group's toggle button, sets the event log's `scrollTop`, then advances `vi.useFakeTimers()`
  past `STALENESS_FACTOR * POLL_INTERVAL_SECONDS` with **no** MQTT message dispatched. Asserts,
  using `toBe` on captured DOM node references (not `toEqual`, not text comparison): the badge
  flips to STALE, both groups stay expanded, the unaffected group's row is the identical DOM
  node, focus is preserved on the identical element, `scrollTop` is unchanged, and the map
  placeholder's DOM node identity is preserved.
