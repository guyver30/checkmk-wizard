1. **`.sidebar`**: delete `grid-template-rows: var(--layout-sidebar-tree-fraction) 1fr;` — the
   sidebar is single-pane now. `#sidebar-tree` fills it (`height: 100%` or a single `1fr` track).
   Then delete the now-orphaned `--layout-sidebar-tree-fraction` token from `:root` — it is dead
   the moment this rule goes, and CLAUDE.md requires removing orphans your own change creates.
   Split the `.sidebar-tree, .sidebar-events` shared rule if the two panes now need different
   padding; keep `overflow-y: auto` on both — they are the scroll containers `tick()` preserves.

2. **`#centre`** takes over the grid cell `#main` holds today: `grid-row: 4; grid-column: 2;
   display: grid; overflow: hidden;` with
   `grid-template-rows: minmax(0, var(--pane-top-size, 1fr)) auto minmax(0, var(--pane-bottom-size, 260px));`.
   The `minmax(0, …)` is load-bearing: without it a grid item with `overflow-y: auto` refuses to
   shrink below its content and the centre-bottom pane pushes off-screen. The middle `auto` track
   is `#centre-divider` — a real grid track, not an absolutely positioned overlay, so the splitter
   11.1-06 adds gets its hit-target sized by CSS rather than computed in JS. Name
   `--pane-top-size` / `--pane-bottom-size` in a comment as the properties 11.1-06 will set from JS
   on `#centre`.

3. **`#main`**: remove its `grid-row: 4; grid-column: 2;` (it is now a child of `#centre`, not of
   `.shell`). Keep `overflow-y: auto` and its padding. Add `min-height: 0`.

4. **`#centre-divider`**: a 1px rule in `var(--color-border)` with a few px of padding so it reads
   as a boundary — e.g. `height: 5px; background: var(--color-border); background-clip: content-box;
   border-block: 2px solid transparent;`. Leave it non-interactive; 11.1-06 adds `cursor`,
   `role`, focus styling and hit-area.

5. **`#events-pane`**: `display: grid; grid-template-rows: auto minmax(0, 1fr); overflow: hidden;`

7. **Delete the overview rules**: the whole `.overview-card[data-state="…"]` block (7 rules) and
