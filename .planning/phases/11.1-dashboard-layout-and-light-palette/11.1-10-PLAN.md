    - `middleTruncate` inserts a single `…` ellipsis character, never three periods.

distinguishing octet lives in a `192.168.0.x` fleet, which is the entire reason D-35 exists. Guard
non-string and empty input. Head the file with a comment citing the live screenshot behind D-35 so
the tail-bias is not "simplified" away later.

`StateBadgeForState` for `entry.to`.

`displayName(device)` when the device is in the store (alias-first), fall back to `entry.device_id`,

put it in a `title` attribute AND wrap the label in the design system's `Tooltip` with the full
string as `content`. Render the label text as a JSX child; never build it into markup.
