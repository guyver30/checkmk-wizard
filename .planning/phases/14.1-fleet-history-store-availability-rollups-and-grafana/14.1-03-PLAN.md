<interfaces>
History contract (created by plan 14.1-01):
- history.metrics: ts DateTime('UTC'), host, service, metric, value, warn, crit, value_min, value_max, value_sum, value_count. Older than 30 days: rows are 5-minute buckets (value = bucket mean, value_min/value_max = extremes); older than 1 year: 1-hour buckets.
- history.host_state: ts, host, folder, state UInt8 (0 UP, 1 DOWN, 2 UNREACHABLE), in_downtime UInt8, samples.
- history.service_state: ts, host, service, state UInt8 (0 OK, 1 WARN, 2 CRIT, 3 UNKNOWN), samples.
- history.availability_daily (ReplacingMergeTree, read with FINAL): day Date, entity_type ('device' | 'group'), group_type ('' | 'folder' | 'fleet'), entity_key, folder, device_count, up/down/unobserved/downtime/no_data _minutes and _pct, availability_pct Nullable(Float64) (= UP / (UP + DOWN), NULL when no observed UP/DOWN time), schema_version, generated_at. The fleet-wide row has group_type 'fleet', entity_key 'all'.
- ClickHouse HTTP: host clickhouse, port 8123, protocol http, no TLS (internal cmk_net). Grafana user grafana_reader (readonly = 1, max_execution_time changeable); password in container env CH_GRAFANA_PASSWORD.
- Mount (plan 14.1-06): deploy/grafana-provisioning → /etc/grafana/provisioning (read-only).
</interfaces>

1. host-metrics-explorer.json (uid fleet-host-metrics, title "Host metrics explorer", default range now-24h): variables `host` (SELECT DISTINCT host FROM history.metrics ORDER BY host), `service` (SELECT DISTINCT service FROM history.metrics WHERE host = '${host}' ORDER BY service), `metric` (multi, include All; SELECT DISTINCT metric FROM history.metrics WHERE host = '${host}' AND service = '${service}' ORDER BY metric). Panel A, time series "Value (mean per interval)": `SELECT $__timeInterval(ts) AS time, metric, avg(value) AS value FROM history.metrics WHERE $__timeFilter(ts) AND host = '${host}' AND service = '${service}' AND metric IN (${metric:singlequote}) GROUP BY time, metric ORDER BY time`. Panel B, time series "Min / max envelope": min(value_min) and max(value_max) per interval, same filter. Panel C, time series "Thresholds" plotting max(warn) and max(crit) per interval. A text panel noting that data older than 30 days is 5-minute averages and older than 1 year is hourly (D-40b).
2. fleet-state-timeline.json (uid fleet-state-timeline, title "Fleet state timeline", default now-7d): variable `folder` (multi, include All; SELECT DISTINCT folder FROM history.host_state ORDER BY folder). Panel A, state-timeline "Host state": `SELECT $__timeInterval(ts) AS time, host, max(state) AS state FROM history.host_state WHERE $__timeFilter(ts) AND folder IN (${folder:singlequote}) GROUP BY time, host ORDER BY time` with value mappings 0 UP (green), 1 DOWN (red), 2 UNREACHABLE (purple) and a note that max picks the worst state per interval. Panel B, state-timeline "In downtime": max(in_downtime) per host with mappings 0 "no", 1 "downtime". Variable `host` (SELECT DISTINCT host FROM history.service_state ORDER BY host) and Panel C, state-timeline "Service state on ${host}": max(state) per service with mappings 0 OK green, 1 WARN yellow, 2 CRIT red, 3 UNKNOWN orange.
3. availability.json (uid fleet-availability, title "Availability", default now-30d): Panel A, time series "Fleet availability % per day": `SELECT toDateTime(day) AS time, availability_pct FROM history.availability_daily FINAL WHERE group_type = 'fleet' AND day >= toDate($__fromTime) AND day <= toDate($__toTime) ORDER BY time`. Panel B, table "Per device over range": entity_key AS host, folder, sums of up/down/unobserved/downtime/no_data minutes over the range, and `round(sum(up_minutes) / nullIf(sum(up_minutes) + sum(down_minutes), 0) * 100, 3) AS availability_pct` from entity_type = 'device', grouped by host and folder. Panel C, table "Per folder over range": same shape from group_type = 'folder'. A text panel stating the definitions (D-45..D-47): availability = UP / (UP + DOWN); UNREACHABLE shown as unobserved and excluded; scheduled downtime excluded and shown separately; no-data counted as neither; days are Asia/Singapore local (D-49); figures come from the daily rollup, the same source as the JSON/Parquet objects.
