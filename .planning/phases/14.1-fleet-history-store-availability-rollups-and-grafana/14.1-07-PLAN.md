Deployment contract this plan documents (built by plans 14.1-01..06; do not invent other names):
- New compose services: clickhouse (image clickhouse/clickhouse-server pinned, HTTP 8123 internal to cmk_net only, not published), minio-init (one-shot quay.io/minio/mc job creating buckets clickhouse-s3-disk and fleet-availability, anonymous download policy on fleet-availability), grafana (host port 3000, login required).
- minio service image moved from minio/minio:latest to a pinned quay.io/minio/minio RELEASE tag.
- New deploy/.env secrets (all empty-default in compose): CH_ADMIN_PASSWORD, CH_WRITER_PASSWORD, CH_READER_PASSWORD, CH_GRAFANA_PASSWORD, GRAFANA_ADMIN_PASSWORD.
- ClickHouse init scripts (deploy/clickhouse-config/initdb/) run only on the FIRST start with an empty clickhouse_data volume; if they failed (for example empty passwords) the fix is: set the passwords, `podman compose down`, `podman volume rm <project>_clickhouse_data`, `podman compose up -d`.
- Same-origin read paths on the dashboard (port 8090): GET /ch-api/?query=... (dashboard_reader, read-only) and GET /availability/availability/YYYY/MM/YYYY-MM-DD.json, /availability/availability_parquet/date=YYYY-MM-DD/availability.parquet.
- Rollups: written by the poller shortly after 00:05 Asia/Singapore for the previous day, with auto-backfill up to 28 days; never overwritten.
- Live smoke test: `uv run python scripts/smoke_test_history_proxy.py --host <podman-host> --grafana-password "$GRAFANA_ADMIN_PASSWORD"`.
- Compose restart caveat (project memory): use a full `podman compose down` / `up -d`, not a single-service restart of the poller.
