## Pattern Assignments

### `scripts/mqtt_poller.py` (service, extended)

**Analog:** itself — this module's own established conventions (no external file needed; the new code must fit the same module, so its own patterns are the analog).

**Config pattern** (`PollerConfig`, lines 325–405): every new runtime setting is env-var-sourced, added as a field with a default so no positional `PollerConfig(...)` call breaks, and appended to `from_env()`. Follow this exactly for the new S3/Thanos/metrics-port settings (e.g. `S3_ENDPOINT`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `METRICS_PORT`, `AVAILABILITY_BUCKET`, `ROLLUP_TZ`):
```python
@dataclass
class PollerConfig:
    ...
    # Appended after existing fields so no positional PollerConfig(...) call site breaks.
    service_history_max_entries: int = DEFAULT_SERVICE_HISTORY_MAX_ENTRIES

    @classmethod
    def from_env(cls) -> PollerConfig:
        return cls(
            ...
            service_history_max_entries=_env_int(
                "SERVICE_HISTORY_MAX_ENTRIES", DEFAULT_SERVICE_HISTORY_MAX_ENTRIES
            ),
        )
```
Reuse `_env_int`/`_env_float` (lines 297–322) for any new numeric env var — never `int(os.environ[...])` directly, since a typo must degrade with a warning, not crash-loop the container.

**Single-choke-point network error pattern** (`fetch_host_config`, lines 1214–1309; `_livestatus_request`, lines 1181–1204): every new network call (Thanos Query `query_range` HTTP GET, MinIO/S3 `head_object`/`put_object`) must funnel through exactly one function per subsystem that normalizes every failure into one exception type, exactly once:
```python
def fetch_host_config(base_url: str, username: str, secret: str, timeout: float) -> dict[str, HostConfigInfo]:
    url = f"{base_url}/domain-types/host_config/collections/all"
    try:
        request = urllib.request.Request(
            url,
            headers={"Authorization": f"Bearer {username} {secret}", "Accept": "application/json"},
        )
        with urllib.request.urlopen(request, timeout=timeout) as response:
            data = json.loads(response.read())
    except (
        urllib.error.HTTPError,
        urllib.error.URLError,
        OSError,
        TimeoutError,
        json.JSONDecodeError,
    ) as exc:
        raise RestError(f"REST host-config lookup to {url} failed: {exc}") from exc
    ...
```
For the new rollup job's Thanos Query fetch, define a new `ThanosQueryError(RuntimeError)` (mirroring `LivestatusError`/`RestError` at lines 285–295) and a single `_thanos_query_range(...)` choke-point function. For the S3 writer, `boto3`'s `ClientError` is already the normalized exception type — no extra wrapper class needed, but still isolate the call in one small function (`write_day_if_absent`, per RESEARCH.md Pattern 3) rather than inlining `s3.put_object(...)` at multiple call sites.

**Graceful-degradation posture** (`run_forever`, lines 2569–2634): a new-subsystem failure (Thanos Query unreachable for the midnight job, S3 unreachable) must degrade the *specific* new feature only, never the mandatory Livestatus poll cycle — same pattern as the existing REST folder lookup:
```python
rest_ok = False
try:
    last_host_config = fetch_host_config(...)
    rest_ok = True
except RestError as exc:
    _logger.warning("Reusing last known host-config map; REST refresh failed: %s", exc)
```
Apply the same shape to the midnight rollup job: catch `ThanosQueryError`/`ClientError` around one day's computation, log a warning, and continue to the next day/host — a single bad day must never abort the whole backfill sweep (D-52).

**Pure-function pattern for business-rule computation** (`compute_incidents`, lines 778–939; `parse_perf_data`, lines 1134–1178; `classify_host_services`, lines 986–1089): `compute_daily_availability()` (RESEARCH.md Pattern 2) must be written the same way — a plain function taking already-fetched data (no I/O inside it), heavily commented with the *why* of each business rule (D-45/D-46/D-47 exclusions), unit-testable with hand-built fixture lists exactly like `compute_incidents`.

**Startup probe + bounded retry pattern** (`run_forever`, lines 2477–2505, using `_STARTUP_RETRY_DELAYS_SECONDS = (5, 10, 15)` at line 280): if the new `/metrics` HTTP server or the midnight-job's startup backfill needs a bounded retry (e.g. Thanos Query not yet ready at container start), reuse this exact tuple-of-backoff-seconds idiom — do not add a retry/backoff library.

**Never-mutate-in-place helper pattern** (`append_bounded`, lines 645–647): the rollup job's per-day JSON payload construction should follow the same "build a new dict/list, never mutate a shared one" discipline already used throughout this file's publish helpers.

**CLI diagnostic flag pattern** (`main()`, lines 2644–2801, especially `--check-columns` and `--dump-service-names`): if the planner wants a manual verification hook for the new `/metrics` endpoint or a one-shot rollup run, add it as a new `argparse` flag here (e.g. `--run-rollup-once`), following the exact same "parse args, branch before `run_forever()`, `configure_logging` first thing, return an int exit code" shape as the two existing flags.

## Shared Patterns

### Env-var-only configuration, no config files
**Source:** `scripts/mqtt_poller.py` `PollerConfig.from_env()` (lines 378–405), `_env_int`/`_env_float` (lines 297–322)
**Apply to:** every new poller setting (S3 endpoint/keys, metrics port, rollup bucket name, backfill window)
```python
def _env_int(name: str, default: int) -> int:
    raw = os.environ.get(name)
    if not raw:
        return default
    try:
        return int(raw)
    except ValueError:
        _logger.warning("Invalid integer for %s=%r; using default %r", name, raw, default)
        return default
```

### Single-choke-point network error normalization
**Source:** `_livestatus_request` (`scripts/mqtt_poller.py:1181-1204`), `fetch_host_config` (`scripts/mqtt_poller.py:1214-1309`)

```python
def _livestatus_request(host: str, port: int, query: str, timeout: float) -> str:
    try:
        with socket.create_connection((host, port), timeout=timeout) as sock:
            ...

    return b"".join(chunks).decode(errors="replace")
```
