## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Trusting unverified container config | Two 14.1 deploy bugs only surfaced on the first live start: minio-init's plain-string `command:` was split by compose (sh got only "until"), and ClickHouse 26.9 rejected the MinIO guide's double-slash S3 endpoint (Code 36). Both passed every offline check. | advisory | For any new compose/entrypoint script, use the list-form `entrypoint: [sh, -c, >- script]`; treat vendor "integration guide" snippets as unverified until a live start confirms them |
| Restarting a single container | `podman compose restart poller` once cut Checkmk off from the LAN (project memory) | advisory | Use full `podman compose down && up -d`; `podman stop/start clickhouse` for the outage test is fine |
