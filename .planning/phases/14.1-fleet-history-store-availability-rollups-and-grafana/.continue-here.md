## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Unsupported compose flags | `podman compose config -q` fails on podman-compose 1.0.6 (host package); reset-site.sh pre-flight falsely reported an incomplete .env | advisory | Check flags against podman-compose 1.0.6 (`uv run --with podman-compose==1.0.6 podman-compose <cmd> --help`); never swallow compose stderr |
| Single-container restart | `compose restart poller` cut Checkmk egress (all hosts DOWN) | advisory | Always full `podman compose down` / `up -d` |
