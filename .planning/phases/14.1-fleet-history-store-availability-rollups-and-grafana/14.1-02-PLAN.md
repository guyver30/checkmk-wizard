## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Livestatus → poller | perf_data strings and service names come from monitored hosts' plugins |
| poller → ClickHouse (cmk_net) | writer credential sent over internal HTTP |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14.1-08 | Tampering | INSERT statement built in _clickhouse_insert | mitigate | Table name must be in CLICKHOUSE_INSERT_TABLES; row values travel only in the JSONEachRow body (json.dumps), never in the SQL text |
| T-14.1-09 | Denial of Service | ClickHouse outage stalling the poll loop | mitigate | 5 s timeout per request, write after MQTT publish, per-table try/except, drop on failure with no retry (D-44) |
| T-14.1-10 | Information Disclosure | writer password | mitigate | Sent as X-ClickHouse-Key header, never in URL; masked in PollerConfig.__repr__; error messages never include it |
| T-14.1-11 | Denial of Service | key cardinality from hostile perf_data labels | accept | Labels come from the operator's own Checkmk plugins on ~50 hosts; LowCardinality columns absorb thousands of labels; plugin_output never stored (Pitfall 5) |
| T-14.1-12 | Tampering | NaN/inf values breaking a batch | mitigate | build_history_rows skips non-finite values; json.dumps(allow_nan=False) as a second guard |
</threat_model>
