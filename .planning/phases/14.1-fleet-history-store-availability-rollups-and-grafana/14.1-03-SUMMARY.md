## Decisions Made
- Datasource/provider field names and the `$VAR` provisioning expansion were confirmed live via context7 against `clickhouse/clickhouse-docs` and `grafana/grafana` official docs before writing the files (per the plan's `<action>` instruction), not assumed from training data alone.
- The dashboard panel/variable query-target shape (`editorType: "sql"`, `rawSql`, numeric `format`) follows the `grafana-clickhouse-datasource` plugin's documented Format enum (1=TIMESERIES, 2=TABLE). context7 does not index the plugin's own GitHub repo (`grafana/clickhouse-datasource`) — only `clickhouse/clickhouse-docs`, which confirms the macros (`$__timeFilter`, `$__timeInterval`) and the datasource's general SQL-editor approach but not the exact per-target JSON field enumeration. This is flagged per the plan's own escape hatch ("if they differ from those below, use the docs and note it in the SUMMARY").

## Assumption Drift (advisory)

- **Planned assumption:** the plan's `<action>` text assumes the query-target JSON shape (`editorType`, `rawSql`, `format`, `queryType`) can be "confirmed" via context7 docs the same way the datasource YAML fields were.
- **What turned out true:** context7's ClickHouse docs library confirms the SQL-editor concept and macros (`$__timeFilter`, `$__timeInterval`) but does not carry the `grafana-clickhouse-datasource` plugin's own TypeScript source (its Format/EditorType enums), so the exact numeric `format` values (1=timeseries, 2=table) come from the plugin's documented/well-established public schema rather than a context7-cited source this session.
- **Why it matters:** if Grafana renders a panel with the wrong `format` value, it would show as a misconfigured visualization type rather than an error — a reader evaluating "was this verified against docs" should know the datasource/provider files were doc-verified this session, while the per-panel target's numeric `format` field was not independently re-confirmed against the plugin's own source in this session.
- **Why:** no context7 library indexes `grafana/clickhouse-datasource` directly; `clickhouse-docs` and `grafana/grafana` were the only two libraries available for verification.
