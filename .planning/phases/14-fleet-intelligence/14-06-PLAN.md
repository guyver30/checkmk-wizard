<objective>
Implement DASH-17 kiosk/wall mode (D-14): a URL-entered, chrome-free, auto-rotating, read-only view for lobby/boardroom screens.

Purpose: unattended signage showing incidents and topology.
Output: `useKioskRotation` hook, `KioskView`, and a kiosk branch in `App.tsx` (not IndexRoute, so this plan has no file overlap with the other wave-4 plan 14-05 and stays independent of the edit-mode machinery).

Discretionary choices (D-14, resolved by UI-SPEC, adopted verbatim): entry `?kiosk=1` on `/`; rotation 20 s; 300 ms opacity crossfade; kiosk font scale `text-[1.15em]`; "Enter full screen" button shown once per load, hidden after press or 10 s; `aria-live="polite"` view label "Incidents"/"Topology"; thin accent progress bar. Both views stay mounted and are crossfaded (the vis-network canvas is never torn down per rotation). Kiosk never renders edit controls even when `isTopologyEditingConfigured()` is true (defense in depth).
</objective>
