## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Omitted keys in vis-network updates | TopologyMap applies visuals via `nodes.update()`, which merges; a conditional property omitted in the "normal" case stays stale (recovered hosts stayed faded, fixed 51d50df) | advisory | Always set every conditional visual property explicitly; test dimmed -> normal on the SAME mounted DataSet |
| GUI "Fake check results" for live tests | Checkmk's next real check (~1 min; no-IP hosts always UP) overwrites fakes, often before the 60 s poller reads them; 2.4 GUI didn't show "Disable active checks" | advisory | Use the Livestatus `cmk()` helper (DISABLE_HOST_CHECK / PROCESS_HOST_CHECK_RESULT / ENABLE_HOST_CHECK) from `docs/Incident demo with fake check results.md` |
| Reused worktrees on a stale base | Several executor worktrees started on old commits and hard-reset to the expected base | advisory | Keep the worktree_branch_check block in every executor prompt; verify base in the report |
