<objective>
Build the poller's root-cause incident engine and its retained MQTT publishing (PLR-14, PLR-15, and the publish/tombstone + worst-affected-criticality half of PLR-16). This is the evidence-framing foundation D-06 says must ship and be verifiable before criticality/dependency editing.

Purpose: turn N independent DOWN/UNREACH alarms into one incident per root cause (D-10, D-11), computed once in the poller for every viewer (D-13), re-derived from Livestatus every cycle with no persisted state.
Output: pure `compute_incidents()` + publish/tombstone helpers + run_cycle/reconcile_state integration, with flat pytest tests.

Criticality/depends_on LABEL READING is NOT in this plan (that is plan 14-07, after the evidence-framing checkpoint). This plan adds the `criticality`/`depends_on` fields to `DeviceSnapshot` with safe defaults and implements the worst-affected closure against them, so the incident payload contract is final from wave 1 and 14-07 only has to populate the fields.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Livestatus → poller | host names, parents, states, last_state_change are data from Checkmk (hosts can be created outside the wizard) |
| Retained broker state → poller (reconcile) | retained `lan/incidents/+/status` topics are untrusted input at startup |
| Poller → Mosquitto → browsers | incident payloads are read by every dashboard viewer via the read-only `wsreader` ACL (`topic read lan/#`) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Tampering | incident topic ids built from host names | mitigate | root ids come only from snapshots that already passed `is_publishable_device_id` in `query_devices`; reconcile only accepts ids with `INCIDENT_ID_PREFIX` that pass `is_publishable_device_id` |
| T-14-02 | Denial of Service | compute_incidents parent/depends_on graph walks | mitigate | every upward walk and the dependents BFS carries a visited set; parent-cycle test proves termination |
| T-14-03 | Denial of Service | malformed last_state_change / retained incident payloads | mitigate | last_state_change parse degrades to None; reconcile only reads the topic name, never parses the retained payload body |
| T-14-04 | Information Disclosure | new lan/incidents/# topics | accept | contain only host ids/states already published on lan/devices/#; same read-only ACL; no credentials |
| T-14-05 | Tampering | browsers publishing fake incidents | mitigate | unchanged Phase 8 ACL: `wsreader` is `topic read lan/#` only (deploy/mosquitto.acl); no ACL change in this plan |
</threat_model>
