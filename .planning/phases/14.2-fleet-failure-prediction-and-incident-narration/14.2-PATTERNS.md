**Analog:** `scripts/mqtt_poller.py`

Pin paho-mqtt==2.1.0 and use `CallbackAPIVersion.VERSION2` (same as poller). Do not subscribe to bare `lan/#` (research Pattern 4).

**on_message routing by relative topic** (lines 4043-4096, `reconcile_state`):
```python

    ...
```

Ignore zero-length payloads (tombstones) when restoring; validate ids with a regex before using them in a topic.

**Signals and loop** (lines 4500-4510):
```python
stop_event = threading.Event()
def _handle_signal(signum, frame):
    stop_event.set()
signal.signal(signal.SIGTERM, _handle_signal)
signal.signal(signal.SIGINT, _handle_signal)
while not stop_event.is_set():
```

Use `stop_event.wait(EVAL_INTERVAL_SECONDS)` for the 900 s cycle so shutdown is immediate. Guard re-entrancy (Pitfall 14) with a lock; the loop body must never raise out (catch broadly at the cycle level, log, continue; ClickHouse down is a degraded cycle, never fatal, same as the poller's D-44 posture).

**Entry point** (`main`, 4605+): `config = Config.from_env()`; `set_site_id(config.cmk_site_id)` inside try/except ValueError, print `error: ...` to stderr, return 2; warn when `CMK_SITE_ID` is not in `os.environ`. `analytics/__main__.py` is a thin `raise SystemExit(main())` shim (as `src/checkmk_wizard/__main__.py`).

```python
def set_site_id(site_id: str) -> None:   # raises ValueError on a bad id; sets _site_prefix = f"sites/{site_id}/"
def site_topic(suffix: str) -> str:
    if _site_prefix is None:
        raise RuntimeError("set_site_id() was not called")
    return _site_prefix + suffix
def relative_topic(full: str) -> str | None:
    if _site_prefix is not None and full.startswith(_site_prefix):
        return full[len(_site_prefix):]
    return None
```

## Shared Patterns

### Per-site MQTT topic convention
**Source:** `scripts/mqtt_poller.py` 690-720 (Python), `dashboard-react/src/lib/topics.ts` (TS)
**Apply to:** every new topic in analytics and the dashboard. Python builds topics only through `site_topic()`; TS only through `siteTopic()`/`stripSitePrefix()` in `topics.ts`/`mqttClient.ts` (stores and components only ever see relative topics). Site id validated by `/^[A-Za-z][A-Za-z0-9_]{0,15}$/` (Python raises `ValueError`; TS `SITE_ID_RE` in `runtimeConfig.ts`).

### Retained snapshot + tombstone contract
**Source:** `scripts/mqtt_poller.py` `_publish_json` (3584), `publish_incident_tombstone` (3722); `useAppStore.ts` incident branch
**Apply to:** needs, forecasts, narration. Publisher: `qos=1, retain=True`, tombstone = `payload=None, retain=True, qos=1` then `wait_for_publish(timeout=5)`. Consumer: replace whole slot, zero-length = delete key, malformed = ignore and keep last-known-good, never throw out of the message handler. Dashboard clears slices on every (re)connect before the retained replay.

### Untrusted command input
**Source:** `parse_admin_command` (poller 1175) and `adminMode.ts` `buildAdminCommand`/`parseAdminAck`
**Apply to:** `analytics/triage.py` and the dashboard triage publisher. Browser input is untrusted; regex-validate every id used downstream; whitelist actions; commands never retained; ignore retained deliveries; dedup by id.

### Error handling and degradation
**Source:** `_clickhouse_request` / `_publish_json` (poller), `loadRuntimeConfig` (TS)
**Apply to:** all analytics I/O and `historyClient.ts`. One choke point per external system that converts every failure into a single typed error; the loop logs and continues (ClickHouse or S3 down = degraded cycle, never fatal); TS fetch helpers never reject and resolve to a safe default. Secrets never appear in exception text or `__repr__`.

### Pure modules and tests
**Source:** `tests/test_mqtt_poller.py` (module loaded by `importlib.util.spec_from_file_location`, autouse site fixture, no live I/O) and CLAUDE.md "one test file per source file, mocked I/O"
**Apply to:** `tests/test_analytics_<module>.py`. `analytics/` is a real package, so tests can `import analytics.fit` directly (add `analytics` to pytest's import path via `pyproject.toml` `[tool.pytest.ini_options] pythonpath` only if needed; check there is no existing config). Run with `uv run pytest`. Dashboard: `npm test` (vitest).

### Module documentation style
**Source:** CLAUDE.md "Comments" + poller docstrings
**Apply to:** all new Python. `from __future__ import annotations` at top, module docstring with phase/purpose and verification sources, docstrings that explain why, regression tests commented with the bug they guard. Cite how any ClickHouse/Mosquitto behaviour was verified (live or ctx7).

### Deployment convention
**Source:** `deploy/compose.yaml` poller service; memory notes
**Apply to:** analytics service and hand-off docs. The dev machine cannot run podman; live steps (init-env, full `down`/`up -d`, migration via `podman exec -i`) are handed to the user. Never recommend restarting a single container (restarting one breaks Checkmk egress; use full down/up). Update `docs/Podman setup for checkmk, minio, mosquitto, worker.md`, `docs/MQTT-CONTRACT-WALKTHROUGH.md`, `docs/DEPLOY-NEW-MACHINE.md` as RESEARCH lists.
