<feature>
  <name>Field-gated template narration</name>
  <files>analytics/narrate.py, tests/test_analytics_narrate.py</files>
  <behavior>
    Open incident (times rendered as HH:MM in the passed tz; no elapsed durations; format_duration is used only by the closed summary and need one-liners):
    - Headline when root_state == "DOWN" and not inferred: "{root} ({crit} criticality) has been DOWN since {HH:MM}." The "({crit} criticality)" part only when root_criticality is given; "since {HH:MM}" only when `since` parses, otherwise "{root} is DOWN." No elapsed duration in open narration text: it would go stale between publishes, and the incident card already renders the live elapsed time from the incident's `since` (formatIncidentDuration in dashboard-react/src/lib/incidents.ts)
    - root_state UNREACH (or anything other than DOWN): "{root} has not been observable since {HH:MM}." never the word DOWN for the root
    - inferred true: "{root} is the inferred common cause since {HH:MM}." never DOWN
    - confirmed_down non-empty: "{n} device(s) behind it are DOWN: a, b." (n=1 uses "1 device behind it is DOWN: a.")
    - not_observable non-empty: "{n} devices behind it cannot be observed: cam1, linux1."
    - dependents key present and empty: "No dependent devices are affected."; non-empty: "{n} dependent devices may be affected: x, y."; key absent: no dependents sentence
    - Name lists show at most 5 names then "and N more"; name_for maps ids to display names when given
    - Empty case: an incident with root and root_state but none of confirmed_down, not_observable, dependents returns the headline with sentences == [] (valid, headline-only); with list fields present, sentences has 1..3 entries (capped at 3, so total 2..4); returns None when `root` is missing
    - D-29 snapshot: incident {root: "sw1", root_state: "DOWN", since 12:02 local, not_observable: ["cam1","linux1"], dependents: []} with root_criticality "low" -> headline "sw1 (low criticality) has been DOWN since 12:02." and sentences exactly ["2 devices behind it cannot be observed: cam1, linux1.", "No dependent devices are affected."]
    - Field absence (parametrized over root_criticality, since, confirmed_down, not_observable, dependents): removing the field removes its phrase; the test asserts the specific phrase is absent
    Closed summary (D-30): "{headline-equivalent opener in past tense}. Closed at {HH:MM} after {duration}." plus "(closed while analytics was offline; time is when it noticed)" only when close_source == "reconcile"; device-list sentences reuse the open rules
    Need one-liners (D-31):
    - trend: "{host} {service} is at {value}{unit}; at the current rate it reaches the critical level ({crit}{unit}) on {crit_date} ({confidence} confidence, {N} days of history)." The value clause only with value, the "reaches ..." clause only with crit and crit_date, the parenthetical only with confidence and history_days
    - sustained: "{host} {service} has been at or over the critical level ({crit}{unit}) for {pct}% of the last {window_hours} h." or, with sustained_fraction None and value given, "{host} {service} is at {value}{unit}, over the critical level ({crit}{unit})."
    - failure host: "{host} has been DOWN since {HH:MM}."; failure service: "{host}: {service} is failing since {HH:MM}."; "since" clause only when since is given
    - numbers rendered with at most 1 decimal, trailing ".0" dropped
  </behavior>
  <implementation>
analytics/narrate.py: `from __future__ import annotations`, module docstring citing D-28..D-31 and the IncidentCard.tsx header rule (never claim an UNREACH/inferred device stopped operating). Each sentence is produced by a small private function that returns `None` when its input is absent; the public functions collect non-None results. Stdlib only (`datetime`, `zoneinfo` not imported here: the caller passes a tzinfo). No f-string ever formats a missing value as "None". Lists are validated: non-list or non-str entries are skipped.

Tests import with `from analytics import narrate`. Because plan 04 (same wave) adds the pytest pythonpath, run this plan's tests with `uv run python -m pytest` (adds the repo root to sys.path, and `analytics/` works as a namespace package even before plan 04 lands its `__init__.py`). Use `datetime(2026, 10, 4, 4, 5, tzinfo=UTC)` as now and `ZoneInfo("Asia/Singapore")` (needs tzdata, already a project dependency) in tests.
