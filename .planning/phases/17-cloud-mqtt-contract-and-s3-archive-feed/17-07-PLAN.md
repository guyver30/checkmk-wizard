| wizard -> deploy/.env (holds secrets) | The wizard rewrites a secrets file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-29 | Tampering / Injection | SITE_SEN value | mitigate | `_SEN_RE` fullmatch at prompt, at env read and before write; writer refuses values outside `[A-Za-z0-9_.:-]` so no newline or shell/sed/nginx metacharacter can enter the file |
| T-17-30 | Information disclosure | deploy/.env rewrite | mitigate | Atomic temp-file write keeps the original 0600 mode; only the SITE_SEN line changes; no other value is printed |
| T-17-31 | Denial of service | corrupting deploy/.env | mitigate | Write to a temp file then os.replace; on any OSError the original is untouched and the operator gets the line to add by hand |
| T-17-32 | Tampering | tests writing the real deploy/.env | mitigate | Autouse fixture redirects _DEPLOY_ENV_FILE to tmp_path and stubs the prompt for all run() tests |
