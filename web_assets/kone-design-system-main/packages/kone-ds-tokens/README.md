@import "~kone-ds-tokens/dist/css/variables.css";

### Running commands

A recommended way is using Lerna command from the project's home directory, eg:

``` 
npx lerna run build --scope=kone-ds-tokens
```

It's also possible (though not suggested) to navigate to the package and run scripts there, eg:
```
cd packages/kone-ds-tokens
yarn run build
```
